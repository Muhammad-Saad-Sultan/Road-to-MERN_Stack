# JavaScript Fundamentals Quiz App

Welcome to the **JavaScript Fundamentals Quiz App**! This project is a fully interactive multiple-choice quiz game built entirely with **HTML5, CSS3, and Vanilla JavaScript**. It tests users on JavaScript fundamentals while demonstrating DOM manipulation, event handling, ES6 features, and dynamic UI updates without any external libraries.

## Features

- 🎯 10 JavaScript fundamentals multiple-choice questions
- 🔀 Randomized question order on every restart
- 📊 Dynamic progress bar with question counter
- ✅ Instant answer validation with visual feedback
- 🚫 Prevents multiple answers for the same question
- ➡️ "Next Question" button appears only after answering
- 🏆 Final score, percentage, and performance message
- 📝 Per-question review showing correct/incorrect answers
- 🔄 Restart functionality without reloading the page
- ⚡ Built using modern ES6 JavaScript features

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/quiz-app.git
```

2. Open the project folder.

```bash
cd quiz-app
```

3. Open **index.html** in your browser.

No installation or external dependencies are required.
